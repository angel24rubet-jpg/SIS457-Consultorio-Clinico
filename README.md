# 🏥 Consultorio Clínico BUENA SALUD

## 📋 Descripción del Proyecto

Consultorio Clínico BUENA SALUD es un sistema informático desarrollado para gestionar de manera eficiente la información de pacientes, médicos, especialidades, citas médicas e historiales clínicos.

El objetivo principal es optimizar los procesos administrativos y médicos del consultorio, facilitando el registro, consulta y actualización de información de forma rápida, segura y organizada.

---

## 🎯 Objetivo General

Desarrollar un sistema de gestión para el Consultorio Clínico BUENA SALUD que permita administrar pacientes, médicos, citas e historiales clínicos, mejorando la atención y el control de la información.

---

## ⚙️ Funcionalidades

- 👥 Gestión de pacientes.
- 👨‍⚕️ Gestión de médicos.
- 🩺 Gestión de especialidades.
- 📅 Programación y control de citas médicas.
- 📋 Registro de historiales clínicos.
- 🔍 Búsqueda de información.
- 📊 Generación de reportes.
- 🔐 Control de acceso al sistema.

---

## 🗄️ Módulos del Sistema

### Pacientes
- Registro de pacientes.
- Actualización de datos.
- Consulta de información.

### Médicos
- Registro de médicos.
- Asignación de especialidades.
- Gestión de disponibilidad.

### Especialidades
- Registro de especialidades médicas.
- Asociación con médicos.

### Citas Médicas
- Programación de citas.
- Modificación y cancelación.
- Consulta de agenda.

### Historial Clínico
- Registro de diagnósticos.
- Registro de tratamientos.
- Seguimiento médico.
